# 高利剑 · 学术主页

为 GitHub Pages 制作的中文学术主页，使用原生 HTML / CSS / JavaScript，无构建步骤、无外部字体或运行依赖。适配手机与桌面，支持主题切换、论文筛选与研究主题展开。

## 本地预览

在本目录运行 `python3 -m http.server 4173`，浏览 `http://localhost:4173`。

## 发布至 GitHub Pages

目标账号：`ljgao-ujs`。主页仓库名：`ljgao-ujs.github.io`。

1. 在该账号下创建上述名称的仓库，将本目录内容推送到 `main` 分支。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)`，点击 Save；之后更新 `main` 会自动部署。
4. 部署成功后，地址为 `https://ljgao-ujs.github.io/`。

仓库只包含公开主页源码、部署说明和原创演示音频，不包含本地个人材料原件。`.nojekyll` 使 GitHub Pages 直接提供静态文件。使用相对资源路径，也支持项目仓库子路径部署。

发布配置参考：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 修改内容

- `index.html`：简介、项目、教育工作经历、教学、奖励与邮箱。
- `content.js`：论文条目。可按现有字段添加，列表与筛选会自动更新。
- `styles.css`：布局、配色和响应式样式。
- `app.js`：筛选、导航、主题与概念声波。
- `interactions.js`：沿鼠标轨迹延伸的频谱音柱拖尾、点击时的三重声场涟漪、卡片光晕与倾斜、声波视差、滚动入场及阅读进度。音柱以约 6px 间距排列，最多 48 根，随移动速度起伏，停下约 650ms 后淡出；触屏自动停用光标与视差，遵循系统减少动态效果设置。频谱为视觉反馈，不采集或播放音频。
- `demos.js`：声音事件检测的预设标注与播放进度同步，以及演示音轨互斥播放。
- `demos.css`：任务演示的响应式布局与时间标注样式。
- `assets/demos/`：原创合成提示音、节奏声及混音，可通过 `python3 scripts/generate-demo-audio.py` 重新生成。三个 WAV 均为 6 秒，混音在 PCM 样本上等于两条源轨相加。Demo 不执行检测或分离推理，分轨是已知的原始源轨。

## 内容依据与发布前核对

主页信息取自本地 2026 年江苏大学青年英才申报表。网页没有附带申报表原件、私人电话、出生日期或其他个人身份材料。没有将申报中的预期成果或拟邀请导师写为既成事实。

根据本人后续核正，江苏省科学技术奖二等奖年份为 **2025**；研究方向调整为声音事件检测、声音分离及语义与多模态表征。在研项目保留正式立项名称。

镇江市科技计划项目依据本地正式项目合同补充：社会发展面上项目，编号 SH2025108，名称为“大模型语义指导的开放环境异常声音事件检测技术研究”，负责人高利剑，起止时间 2025.10—2028.09。网页仅展示项目公开概况，不附合同原件。

论文条目采用原材料中的题名、年份、期刊/会议及作者身份；尚未逐篇核对完整作者列表和 DOI，所以提供带完整标题的 Google Scholar 检索入口。研究主题为题名的中文概述，不是原文摘要。

声波图为原创概念插画，不是实验数据。未放置不确定身份的照片。尚未配置个人 Scholar ID、ORCID 或简历下载，避免无效链接。

当前网页以中文为主，英文用于姓名、论文与栏目辅助标识。
